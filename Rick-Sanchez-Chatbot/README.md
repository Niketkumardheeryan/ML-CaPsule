# Rick Sanchez AI Chatbot

A conversational AI chatbot inspired by Rick Sanchez using DialoGPT and Hugging Face Transformers.

## Features
- Dataset preprocessing
- Dialogue generation
- Transformer fine-tuning
- Conversational chatbot

## Tech Stack
- Python
- PyTorch
- Hugging Face Transformers
- DialoGPT
- Pandas

## Run

```bash
python preprocess.py
python train.py
python generate.py
