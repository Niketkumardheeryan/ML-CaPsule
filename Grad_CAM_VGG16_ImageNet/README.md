# Grad-CAM using VGG16 on ImageNet

## Overview
This project demonstrates Grad-CAM (Gradient-weighted Class Activation Mapping) using a pre-trained VGG16 model on ImageNet images.

## Features
- CNN Explainability
- Heatmap Generation
- Visualization of Important Regions
- Google Colab Compatible

## Technologies Used
- Python
- TensorFlow/Keras
- OpenCV
- Matplotlib

## Reference
Selvaraju et al.
"Grad-CAM: Visual Explanations from Deep Networks via Gradient-based Localization"
