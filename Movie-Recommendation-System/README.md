# Movie Recommendation System

## Overview
This project explores movie recommendation techniques and prediction methods using data from MovieLens and TMDB.

## Recommender Systems
Recommender systems suggest items based on prior behavior, similar items, or both. A common example is a streaming app suggesting movies based on what a user watched, rated, or searched for.

## Approach
The project is split into the following steps:

- Data collection from MovieLens and TMDB endpoints
- Data wrangling and cleaning
- Exploratory data analysis
- Machine learning for movie success and revenue prediction
- Recommendation systems based on multiple strategies

## Recommendation Methods
- IMDB weighted rating
- Content-based filtering
- User-based collaborative filtering
- Item-based collaborative filtering

## Collaborative Filtering
User-based collaborative filtering builds a user-item matrix and compares users based on similarity in behavior. Item-based collaborative filtering flips that idea around and compares items instead of people, which is often more efficient when there are fewer items than users.
