# 🫀 Heart Disease Risk Prediction

## 🎯 Objective
The main goal of this project is to build a Machine Learning model that can predict the risk of heart disease in a patient based on their medical attributes. This project is a part of my contribution to GSSoC '26.

## 📊 Dataset
The model is trained on the standard **Cleveland Heart Disease dataset**. It contains 303 patient records with 13 features (like age, cholesterol, chest pain type, max heart rate, etc.) and 1 target variable.

## 🛠️ Libraries Used
* **Pandas:** For reading and analyzing the tabular data.
* **Matplotlib & Seaborn:** For Exploratory Data Analysis (EDA) and visualizing correlation heatmaps.
* **Scikit-Learn:** For splitting the data and training the Machine Learning model.

## 🧠 Model & Accuracy
* **Algorithm Used:** Logistic Regression
* **Data Split:** 80% Training, 20% Testing
* **Achieved Accuracy:** **88.52%** ## 🚀 How to Run
1. Open the `heart_disease_analysis.ipynb` file in a Jupyter Notebook environment (like VS Code or JupyterLab).
2. Run the cells sequentially.
3. Ensure you have an active internet connection as the dataset is fetched directly via a raw GitHub URL.
