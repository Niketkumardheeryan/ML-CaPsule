 # Scam SMS Detector

## Overview
This project detects whether an SMS is spam or safe using Machine Learning and NLP.

## Features
- Spam detection
- Flask web interface
- NLP-based text processing

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas

## Dataset
SMS Spam Collection Dataset

## How to Run
on terminal write 
pip install flask pandas scikit-learn
python app.py
