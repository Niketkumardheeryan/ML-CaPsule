# Matplotlib for Machine Learning

Visualization is a critical skill in Machine Learning for understanding
data patterns, distributions, and model behavior.

## Notebooks in this folder

- `Matplotlib_Fundamentals.ipynb` — Core plotting concepts and syntax
- `Matplotlib_Titanic_ML.ipynb` — EDA and ML-focused visualization on real data

This folder introduces:
- Matplotlib fundamentals
- Data visualization techniques
- ML-oriented visual analysis using real datasets

The Titanic notebook demonstrates how visualization supports
feature understanding and exploratory data analysis.
