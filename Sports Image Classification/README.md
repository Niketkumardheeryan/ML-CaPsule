# Sports Image Classification

## Overview

This project classifies sports images into different categories using deep learning and computer vision techniques.

## Features

* Image preprocessing
* Sports category prediction
* Deep learning based classification
* Model training and evaluation

## Technologies Used

* Python
* TensorFlow/Keras
* OpenCV
* NumPy

## Project Structure

```text
Sports Image Classification/
│── Images/
│── model/
│── notebook.ipynb
│── README.md
```

## Setup Instructions

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the training or prediction script

```bash
python app.py
```

## Dataset

The dataset consists of categorized sports images used for model training and testing.
