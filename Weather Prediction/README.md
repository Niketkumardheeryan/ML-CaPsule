# Weather Prediction

## Overview
This project uses an ARIMA model to forecast weather trends. Model accuracy is evaluated with root mean square error (RMSE), and the reported RMSE for the forecast is 2.24.

## Libraries Required
- `numpy`
- `pandas`
- `matplotlib`
- `scikit-learn`
- `seaborn`
- `statsmodels`
- `pmdarima`
