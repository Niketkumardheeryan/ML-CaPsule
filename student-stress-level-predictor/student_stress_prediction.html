Student Stress Level Prediction¶

Multi-class classification of student stress (0 = low, 1 = medium, 2 = high) using the Student Stress Factors dataset (~1,100 rows, 20 features).

Pipeline

  1. Load data (Colab-friendly upload, or local file)
  2. EDA — distributions, target balance, correlation heatmap
  3. Preprocessing + train/test split
  4. Train Logistic Regression, Random Forest, XGBoost
  5. Evaluate (accuracy, macro F1, confusion matrix)
  6. Feature importance + insights

def synth_dataset(n=1100, rng=RNG):
    rs = np.random.RandomState(rng)
    latent = rs.normal(0, 1, n)
    def clip(x, lo, hi): return np.clip(np.round(x), lo, hi).astype(int)
    df = pd.DataFrame({
        "anxiety_level":               clip(10 + 4*latent + rs.normal(0,2,n), 0, 21),
        "self_esteem":                 clip(18 - 4*latent + rs.normal(0,3,n), 0, 30),
        "mental_health_history":       (rs.rand(n) < 0.4 + 0.15*latent).astype(int),
        "depression":                  clip(13 + 5*latent + rs.normal(0,3,n), 0, 27),
        "headache":                    clip(2.5 + 0.7*latent + rs.normal(0,0.7,n), 0, 5),
        "blood_pressure":              clip(2 + 0.4*latent + rs.normal(0,0.4,n), 1, 3),
        "sleep_quality":               clip(3 - 0.8*latent + rs.normal(0,0.8,n), 0, 5),
        "breathing_problem":           clip(2.3 + 0.7*latent + rs.normal(0,0.8,n), 0, 5),
        "noise_level":                 clip(2.5 + 0.5*latent + rs.normal(0,0.8,n), 0, 5),
        "living_conditions":           clip(2.7 - 0.6*latent + rs.normal(0,0.8,n), 0, 5),
        "safety":                      clip(3 - 0.8*latent + rs.normal(0,0.8,n), 0, 5),
        "basic_needs":                 clip(3 - 0.7*latent + rs.normal(0,0.8,n), 0, 5),
        "academic_performance":        clip(3 - 0.7*latent + rs.normal(0,0.8,n), 0, 5),
        "study_load":                  clip(2.5 + 0.7*latent + rs.normal(0,0.8,n), 0, 5),
        "teacher_student_relationship":clip(2.8 - 0.6*latent + rs.normal(0,0.8,n), 0, 5),
        "future_career_concerns":      clip(2.7 + 0.8*latent + rs.normal(0,0.8,n), 0, 5),
        "social_support":              clip(2 - 0.5*latent + rs.normal(0,0.6,n), 0, 3),
        "peer_pressure":               clip(2.7 + 0.6*latent + rs.normal(0,0.9,n), 0, 5),
        "extracurricular_activities":  clip(2.7 + 0.4*latent + rs.normal(0,0.9,n), 0, 5),
        "bullying":                    clip(2.5 + 0.7*latent + rs.normal(0,0.9,n), 0, 5),
    })
    df["stress_level"] = pd.qcut(latent + rs.normal(0, 0.3, n),
                                 q=3, labels=[0, 1, 2]).astype(int)
    return df

5. Model training & comparison¶

In [9]:
models = {
    "Logistic Regression": LogisticRegression(max_iter=2000, multi_class="multinomial", random_state=RNG),
    "Random Forest":       RandomForestClassifier(n_estimators=300, random_state=RNG, n_jobs=-1),
    "XGBoost":             XGBClassifier(n_estimators=300, max_depth=4, learning_rate=0.1,
                                         objective="multi:softprob", num_class=3,
                                         eval_metric="mlogloss", random_state=RNG, n_jobs=-1),
}

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=RNG)
results = []
fitted = {}

for name, model in models.items():
    Xtr, Xte = (X_train_s, X_test_s) if name == "Logistic Regression" else (X_train, X_test)
    cv_f1 = cross_val_score(model, Xtr, y_train, cv=cv,
                            scoring="f1_macro", n_jobs=-1).mean()
    model.fit(Xtr, y_train)
    preds = model.predict(Xte)
    results.append({
        "Model": name,
        "CV macro-F1": round(cv_f1, 4),
        "Test accuracy": round(accuracy_score(y_test, preds), 4),
        "Test macro-F1": round(f1_score(y_test, preds, average="macro"), 4),
    })
    fitted[name] = (model, preds)

results_df = pd.DataFrame(results).sort_values("Test macro-F1", ascending=False)

8. Insights¶

  • Best result — ~88.6% accuracy / 0.886 macro-F1 across all three models on the real Kaggle data.
  • Top correlations with stress: self_esteem, bullying, sleep_quality, future_career_concerns, anxiety_level, depression.
  • Top tree-model importances: blood_pressure, sleep_quality, academic_performance — blood_pressure likely acts as a strong interaction splitter.
  • Linear and tree models score nearly the same, suggesting the signal is largely monotonic.
  • Next steps: hyperparameter tuning, stacked ensemble, SHAP analysis (especially for blood_pressure), engineered interaction features.
