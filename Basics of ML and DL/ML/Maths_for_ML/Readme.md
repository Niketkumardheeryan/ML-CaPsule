# 📐 Math for Machine Learning

Machine Learning often feels like magic until the math behind it becomes clear.

This folder provides a **conceptual + practical math foundation** required to understand
how ML algorithms in this repository actually work.

Each topic is implemented using **NumPy**, visual intuition, and then **mapped directly**
to ML algorithms already present in this repo.

---

## 📂 Topics Covered

| Topic | Folder | Why it matters in ML |
|------|-------|---------------------|
| Linear Algebra | `Linear_algebra/` | Core of neural networks, linear models, vectorized computation |
| Calculus | `Calculus/` | Backbone of optimization and gradient-based learning |
| Probability | `Probability/` | Foundation of probabilistic models and uncertainty |
