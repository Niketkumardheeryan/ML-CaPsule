# E-Waste Impact Calculator 🌍♻️

## Overview
This machine learning module calculates the environmental footprint of electronic devices. It predicts the "Toxic Potential Score" of e-waste based on the gadget's material composition and its estimated lifespan. 

Moving beyond standard predictions, this project aims to bring awareness to sustainability and responsible e-waste disposal.

## Tech Stack
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (RandomForestRegressor, LabelEncoder)
