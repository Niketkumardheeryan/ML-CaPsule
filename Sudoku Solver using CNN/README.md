# Sudoku Solver using CNN

## Overview

This project solves Sudoku puzzles using Convolutional Neural Networks (CNN) and image processing techniques.

## Features

* Sudoku grid detection
* Digit recognition using CNN
* Puzzle solving logic
* Image preprocessing

## Technologies Used

* Python
* OpenCV
* TensorFlow/Keras
* NumPy

## Project Structure

```text
Sudoku Solver using CNN/
│── dataset/
│── model/
│── notebook.ipynb
│── README.md
```

## Setup Instructions

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the application

```bash
python app.py
```

## Dataset

The project uses digit datasets and Sudoku puzzle images for training and testing.
