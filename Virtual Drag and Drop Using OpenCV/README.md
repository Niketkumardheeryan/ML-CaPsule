# Virtual Drag and Drop Using OpenCV

## Overview

This project implements a virtual drag-and-drop system using OpenCV and computer vision techniques. It enables users to interact with on-screen objects using hand gestures.

## Features

* Hand tracking
* Gesture recognition
* Virtual object interaction
* Real-time video processing

## Technologies Used

* Python
* OpenCV
* NumPy
* Mediapipe

## Project Structure

```text
Virtual Drag and Drop Using OpenCV/
│── images/
│── notebook.ipynb
│── app.py
│── README.md
```

## Setup Instructions

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project

```bash
python app.py
```

## Dataset

The project primarily uses webcam input for real-time interaction.
