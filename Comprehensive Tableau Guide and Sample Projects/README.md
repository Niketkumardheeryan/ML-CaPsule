## 🚀 Getting Started

### Prerequisites

You need one of the following:

- **Tableau Public** (Free) — [Download here](https://public.tableau.com/en-us/s/download)
- **Tableau Desktop** (14-day free trial) — [Download here](https://www.tableau.com/products/trial)

and some dataset.
### Using This Guide

1. Clone or download this repository.
2. Open `tableau_guide.md` in any Markdown reader (GitHub, VS Code, Obsidian, etc.).
3. Follow along section by section — earlier sections build the foundation for later ones.
4. For hands-on practice, use the `Dashboard Tutorials.md` Guide along with **Sample - Superstore** dataset that ships with Tableau (no download needed).
