# Human Emotion Detection Using Deep Learning

## Overview

This project implements a **Human Emotion Detection system using Deep Learning**. 
The system analyzes facial images and classifies the detected emotion into different 
categories such as **Happy, Angry, Sad, Neutral, and other emotions**.

Two Convolutional Neural Network (CNN) architectures are explored in this project:

- **LeNet**
- **ResNet**

The models are trained and evaluated for image-based emotion classification to understand 
and compare the performance of different CNN architectures.

## Key Features

1. Facial emotion classification using Deep Learning
2. Image preprocessing and normalization
3. Emotion classification into multiple categories
4. Implementation using **LeNet**
5. Implementation using **ResNet**
6. Model training and validation
7. Prediction of emotions from input facial images
