# Statistical Modeling in Python

This project explores statistical modeling techniques on a retail sales dataset to understand relationships between variables and support exploratory analysis, regression, and hypothesis testing.

## Dataset
- Kaggle retail sales dataset: [retail-sales-dataset](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset)

## About the Data
- Transaction ID: unique identifier for each transaction
- Date: transaction date
- Customer ID: unique identifier for each customer
- Gender: customer gender
- Age: customer age
- Product Category: category of the purchased product
- Quantity: units purchased
- Price per Unit: unit price
- Total Amount: total transaction value

## Workflow
1. Check and handle missing values
2. Detect and remove outliers
3. Encode categorical values
4. Create month, year, and date features
5. Explore the data visually
6. Apply regression analysis
7. Run hypothesis tests

## Exploratory Analysis
- Distribution plots
- Univariate and bivariate analysis
- Total sales by feature
- Bar plots, line plots, histograms, and heatmaps

## Statistical Methods
- Regression analysis
- T-test
- Chi-square test
- ANOVA
- PyCaret AutoML regression

## Libraries
- `pandas`
- `matplotlib`
