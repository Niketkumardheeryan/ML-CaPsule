# Bitcoin-Price-Predictor

## Short description of package/script

- This project demonstrates the prediction of the bitcoin price by the neural network model.
- It includes both a Jupyter Notebook for exploration and a **Premium Streamlit Web Dashboard**.
- We are using long short term memory (LSTM).
- The web app includes a full login system, dark mode UI, Top Navbar, and interactive Plotly charts.

### We will be going through a four-step process to predict cryptocurrency prices:
1. Getting real-time cryptocurrency data (Bitcoin).
2. Prepare data for training and testing.
3. Predict the price of cryptocurrency using LSTM neural network (deep learning).
4. Visualize the prediction results on a live Dashboard.

## Setup instructions

### Prerequisites
You need to install all the necessary libraries in order to run the project.

### Installing
```bash
pip install sklearn tensorflow pandas matplotlib streamlit plotly
```

## Running the Web App
Run the following command to start the web dashboard:
```bash
streamlit run app.py
```
