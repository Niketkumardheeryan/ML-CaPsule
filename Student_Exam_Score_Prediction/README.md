# Student Exam Score Prediction

## Project Overview

This project predicts students' exam scores using machine learning.

The dataset contains information related to students' academic and personal factors such as:

- Age
- Study Hours
- Class Attendance
- Sleep Hours
- Gender
- Course
- Internet Access
- Sleep Quality
- Study Method
- Facility Rating
- Exam Difficulty

The project applies data preprocessing and multiple machine learning algorithms to predict the student's exam score.

---

##  Objective

The main objective of this project is to:

- Analyze factors affecting students' exam performance.
- Preprocess numerical and categorical data.
- Train multiple regression algorithms.
- Compare model performance using regression metrics.
- Predict students' exam scores.
