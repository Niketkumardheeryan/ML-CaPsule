# Learning Rules In ANN

## Overview

This project explores learning rules used in Artificial Neural Networks (ANN) for training and optimization.

## Features

* Neural network learning concepts
* ANN training methods
* Weight update mechanisms
* Educational demonstrations

## Technologies Used

* Python
* NumPy
* Neural Network Concepts

## Setup Instructions

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the project scripts or notebooks

```bash
python app.py
```
