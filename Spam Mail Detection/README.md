# Spam Mail Detection

## Overview

This project focuses on detecting spam emails using machine learning techniques. The model classifies messages as spam or ham based on text features extracted from email content.

## Features

* Text preprocessing
* Spam classification
* Machine learning based prediction
* Model evaluation

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP techniques

## Project Structure

```text
Spam Mail Detection/
│── Dataset/

│── README.md
```

## Setup Instructions

1. Clone the repository

```bash
git clone <repo-url>
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the notebook or script

```bash
python app.py
```

## Dataset

The dataset contains labeled spam and non-spam messages used for training and evaluation.
