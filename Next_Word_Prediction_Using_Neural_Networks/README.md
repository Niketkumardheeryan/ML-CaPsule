# Next Word Prediction using Neural Networks

## Overview
Builds a Next Word Prediction model using LSTM neural networks. 
Given a sequence of words, the model predicts the most likely next word.

## Libraries Used
TensorFlow / Keras
NumPy
Matplotlib

## Model Architecture
Embedding Layer
LSTM Layer (150 units)
Dense Layer with Softmax activation

## Results
Achieved ~89% training accuracy
