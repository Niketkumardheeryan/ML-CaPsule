# Basics of Machine Learning and Deep Learning

This section introduces the foundational concepts required to start a journey
in Machine Learning and Deep Learning.

It is designed for beginners who want to understand **both theory and practice**
without jumping directly into black-box libraries.

---

## 📂 What this section contains

- Mathematical foundations for ML
- Core ML concepts and algorithms
- Visualization techniques
- Conceptual bridges between math and real ML code
