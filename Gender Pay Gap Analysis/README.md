# **Additional Contribution**

**AIM**

The aim of this project is to analyze gender wage gap trends across multiple countries over time and builds a machine learning model to predict the gender wage gap percentage. This aims to expand the analysis of the pay gap over different countries and analyse the trends over the years for every country.

The project combines data preprocessing, feature engineering, predictive modeling, and data visualization to uncover patterns and trends in wage inequality.

**Dataset** 

Dataset can be downloaded from - https://www.kaggle.com/datasets/willianoliveiragibin/gender-economic-inequality

## Objectives

- Analyze gender wage gap trends across countries.
- Compare wage gap distributions between countries.
- Build a predictive machine learning model.
- Evaluate model performance using regression metrics.
- Generate visual insights through exploratory analysis.

## Visualizations

### 1. Heatmap

Country vs Year gender wage gap distribution.

### 2. Average Wage Gap by Country

Bar chart comparing average wage gap across countries.

### 3. Wage Gap Distribution

Boxplot showing variability and outliers for each country.

### 4. Actual vs Predicted

Comparison of model predictions with actual values.

## Results

The analysis highlights:

- Countries with consistently high wage gaps.
- Countries showing improvement over time.
- Temporal trends in wage inequality.
- Predictive patterns captured by the machine learning model.
